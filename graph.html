Graph

Vista de grafo al estilo Obsidian: cada máquina/engagement se conecta con sus tags compartidos. Arrastra los nodos para reordenar, pasa el cursor para resaltar conexiones, haz clic en un writeup para abrirlo.

Todavía no hay suficiente contenido para dibujar un grafo.
